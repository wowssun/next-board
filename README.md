
This is a [Next.js](https://nextjs.org/) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
## 🛠️ Tech Stack
- **Frontend**: Next.js (with Server Actions), TypeScript, Tailwind CSS
- **Backend**: Next.js Server Actions, Prisma, Docker
- **Database**: Prisma ORM with PostgreSQL 
- **Libraries**:
  - **Authentication**: NextAuth (Credentials Provider)
  - **Data Validation**: Zod
  - **Encryption**: bcrypt
- **Environment**: Containerized development with Docker for local use
